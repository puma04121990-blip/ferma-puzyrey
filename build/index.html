📊 СТАТИСТИКА ФЕРМЫ

📖 КАК ИГРАТЬ

  • Цель: стреляйте овощными пузырьками, чтобы собирать группы из 3 и более одинаковых овощей.
  • Управление (мышь/тач): Мышь — двигайте курсор для прицела, клик — выстрел. Тач — зажмите палец (появится траектория прицела), двигайте палец для наведения, отпустите — выстрел. Можно играть одной рукой.
  • Клавиатура: Space — выстрел, Q / Tab — смена текущего и следующего пузыря, 1-4 — инструменты, Esc — пауза, R — рестарт уровня.
  • Смена пузыря: кнопка «Смена» 🔄, тап по лотку «СЛЕДУЮЩИЙ» или Q. Доступна сразу, затем раз в 3 выстрела.
  • Физика: шарики прилипают идеально к гекс-сетке. Падающие группы получают бонусные очки.
  • Потолок: каждые несколько выстрелов грядка опускается. Не дайте овощам дойти до пушки!
  • Инструменты: Лопата, Огородник, Трактор и Урожай доступны с 1-го уровня (ограниченный запас). Когда счётчик стал 0 — нажмите инструмент и посмотрите рекламу VK, чтобы пополнить именно его.
  • Пауза и звук: Есть кнопка паузы (Esc) и выключения звука в HUD.

Комбо и большие группы дают намного больше очков. Старайтесь создавать каскады!
