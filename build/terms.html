Пользовательское соглашение

Игра «Ферма Пузырей» (далее — Приложение) размещается на платформе VK Mini Apps / Игры ВКонтакте. Запуская Приложение, вы принимаете настоящее соглашение, а также применимые Типовое пользовательское соглашение и Правила размещения приложений.

1. Описание

Приложение — HTML5-игра развлекательного характера (аркада «собери группу»). Основные функции доступны внутри клиента ВКонтакте / Одноклассников без обязательного перехода на сторонние сайты.

2. Данные и прогресс

Приложение может сохранять игровой прогресс (уровень, счёт, статистика, настройки) с помощью VK Storage, привязанного к идентификатору пользователя платформы. Обработка данных регулируется Политикой конфиденциальности.

3. Реклама и виртуальные ценности

В Приложении может отображаться реклама рекламной сети VK: вознаграждаемая (только по действию пользователя), между экранами (при переходе к следующему уровню). Игровые инструменты и бонусы используются только внутри Приложения и не обмениваются на реальные деньги.

4. Правила поведения

Запрещается использовать читы, ботов, эксплойты, нарушать работу Приложения или правила платформы ВКонтакте / Одноклассников.

5. Поддержка

По вопросам работы Приложения пользователь может обратиться к разработчику через раздел «О игре» в меню Приложения. Ответ предоставляется в срок, не превышающий 7 календарных дней.

6. Удаление данных

Пользователь может сбросить прогресс кнопкой «Сбросить весь прогресс» в главном меню, а также прекратить использование, удалив Приложение.

7. Возрастные ограничения

Рекомендуемый возрастной рейтинг: 0+. Контент не содержит насилия, эротики, нецензурной лексики и пользовательского контента.
